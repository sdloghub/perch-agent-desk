# Perch 原生界面改造

2026-10-29：根据用户反馈，撤回 React/Radix 外壳作为主界面，直接在原生 Open WebUI 上改造。原型源码保留在 `ui/`，不作为当前设计或必需构建步骤。

2026-10-31：应用图标由字母 P 改为树枝 monogram，表达多个 harness 分枝汇入同一主干；圆角深色底与浅色枝条延续界面配色。内部界面保持极简暗色，只增加一个克制的青色 accent、细边框、输入框柔和聚焦光晕、模型菜单/管理弹窗统一 hover 与 focus 状态，以及首页树枝 mark 与轻微入场动画；`prefers-reduced-motion` 下动画全部关闭。

## 审查与定位

原生布局可继续使用；主要偏差为新增工具条重复边框、路径抢占空间、记忆弹窗灰绿配色、长记忆堆积和移动端工具条换行。用户要求保留原生界面和黑色配色，采用保留式改造。DESIGN_VARIANCE=2、MOTION_INTENSITY=2、VISUAL_DENSITY=6。

沿用上游 Svelte 组件和字体，不再嵌入 iframe 或加载第二套框架。黑灰底色、白色主操作、灰色次操作；控件圆角 7–8px，输入框 14px，管理弹窗 10px。工作区以名称显示，完整路径仍在 tooltip 和管理页中。原生历史侧栏、消息分支、模型选择、附件、停止和工具展示保持上游实现。

两个用户指定 skill 中的审查、排版、对比度、状态与响应式原则应用于此次修改；营销页用的 AIDA、Hero、Bento、随机布局和 GSAP 滚动不适用于用户指定的原生聊天工作台。

## 交互与数据

原生输入框上方提供工作区、继续对话、记忆入口。管理窗口采用同一中性黑色主题和有状态的选项卡。记忆通过现有 catalog API 每页读取 30 条，按需展开全文，保留编辑、删除、范围过滤和新增能力。历史切换继续保留未发送草稿提示。未修改模型路由、记忆数据库或工作区绑定规则。

## 验证

18 项离线运行时回归通过；JS/Python 语法、差异检查和本机 App 签名检查通过。真实浏览器 1280px 与 390px 已检查，390px 页面无横向溢出。历史恢复验证了原模型、消息和 KR 工作区；记忆分页从 30 条加载至 60 条，全文展开正常。初次 Lighthouse：性能 51、可访问性 95、最佳实践 100；已修复可访问性审计指出的按钮标签和上游缩放限制。修复后复测：可访问性 100、最佳实践 100。性能仍受原生前端资源加载影响，不宣称完成性能优化。验收不发起模型推理。截图含本机数据，仅本机保留，不提交公共仓库。


## Gemini / Sonnet 迭代（2026-10-29）

本机 Magpie 的 Gemini 3.8 提供主设计，Sonnet 5.5 辅助审查。首页改为紧凑的品牌标题、工作台输入区与三个文字入口；采用 #101010 主背景、#090909 侧栏、#181818 面板和中性细边框。保留上游聊天组件，移除原欢迎模型名和建议问题的视觉干扰。

`perch_controls.js` 在原生模型菜单上加入供应商一级列表，二级继续使用上游模型选项，保持真实模型 ID、来源和聊天存档行为。搜索跨供应商，支持键盘选择和返回。思考控件按模型能力提供选项，存储每个聊天/模型设置及新聊天的模型偏好，在后续聊天请求中传递给真实 Agent CLI。GLM 使用关闭/高两档，对应其 thinking 开关，不假造额外等级。

桌面 preload 只暴露一个选目录方法，主进程校验窗口、主 frame 和本机 origin 后打开 macOS 原生目录面板。网页模式保留目录管理器。SPA 路由变化会更新工作区和思考控件。

本机设计与自查记录保存在 `design-review/`，截图保存在 `artifacts/screenshots/`；这些包含本机验收材料，不发布到公共仓库。
