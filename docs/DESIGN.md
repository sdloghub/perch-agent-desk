# Perch 界面改造记录

## 原界面审查

现状：Open WebUI 原生深色聊天页，系统无衬线字体，灰绿记忆弹窗，较大圆角；历史、工作区、记忆三种操作集中于输入框上方，管理工作需要反复开关弹窗。原界面偏差/动效/密度约 3/1/4。无公共 SEO 页面，保留原聊天 URL 与全部原生聊天能力。

## 方向

个人 Agent 工作台，冷静的石墨色/浅灰双主题，单一苔绿色强调；系统字体，不下载外部字体。设计参数 DESIGN_VARIANCE=4、MOTION_INTENSITY=2、VISUAL_DENSITY=5。工作台并非营销页，不使用 hero、摄影、滚动动画和营销卡片。使用真实 Radix Themes 组件和 Phosphor 图标，保留 Open WebUI 聊天运行时，用同源嵌入接入实际聊天功能。

整合：持久历史侧栏、工作区选择、聊天面板、记忆管理主面板、统计与来源概览、全局主题切换。原生聊天仍负责分支、消息流、停止、附件和模型选择，避免另建不一致的聊天数据库。App 默认进入 /desk；原 WebUI URL 保留。

## 验收

最终逐项检查键盘焦点、按钮对比、读写错误提示、空态、窄屏折叠、浅/深主题、真实 API 数据、历史恢复和工作区绑定。没有装饰动画，不触发减少动态效果负担。来源标识 Open WebUI 与 Magpie 保持可见。Lighthouse 与实际浏览器结果完成后记录。

2026-10-29 本机验收：宽屏 1280px 与窄屏 390px 均已检查；窄屏侧栏隐藏时不参与键盘焦点。真实历史恢复了原模型与工作区；未发送草稿切换会先显示保留/继续对话框。记忆总数、来源计数、展开和主题切换已通过真实 API 与浏览器核验，未发起模型推理。独立 Perch.app 已签名并启动，实际显示本机工作台。

Lighthouse 初次移动模拟：性能 57、可访问性 95、最佳实践 100。修复顶部文字对比度后，可访问性 100、最佳实践 100。性能 57 仍是当前限制：嵌入的 Open WebUI 原生前端及 Radix 样式有较大的初次加载与未使用资源成本，本次未声称已完成性能优化。源字体本机加载，无外部图片或动画。审计原始文件和界面截图仅本机保留，避免公开真实聊天与记忆。
